Security Architecture

Three layers of defense.
Zero keys in the browser.

Every voice call is gated by an origin check, a scoped JWT, and a DOM sandbox. Each layer is independent; bypassing any single layer is insufficient to compromise the system.

Vector A · Origin
Domain-locked session validation
Every /v1/session request is matched against the customer's allowed origins via strict-suffix hostname check. A key registered for miramarfl.gov cannot start a call from miramarfl.gov.evil.com.
Cloudflare Worker Origin header KV allowlist
Vector B · Navigation
DOM sandbox & URL allowlist
Before any navigate_to or anchor click, embed.js validates the destination against the per-customer navigable_domains list. Cross-origin destinations require explicit allowlist entries.
urlAllowed() Anchor gate policy:<key>
Vector C · Authentication
JWT minting with scoped restrictions
The Worker mints HS256 JWTs scoped to one assistant per customer with a 15-minute TTL. The tag: "public" claim restricts the token to browser web calls — it cannot mutate assistants or touch admin APIs.
HS256 15-min TTL allowedAssistantIds

What counts as a "session"?
A session starts when a user opens the MemorieAI panel and ends when they close it or after 30 minutes of inactivity. One visitor talking through multiple tasks = one session.
Can I use my own Vapi assistant?
Yes. Pro and Enterprise plans let you connect your own Vapi assistant ID via the dashboard. Pass it through the data-key attribute on the script tag.
Do you offer discounts for government or nonprofits?
Yes. Municipalities, public universities, and registered nonprofits qualify for 40% off Pro plans. Reach out to sales with proof of status.
What happens when I exceed my session limit?
We'll notify you at 80% and 100%. On Starter, the bubble pauses until the next billing cycle. On Pro, you can enable auto-overage billing at $0.02/session.
